# 탭탭 라이더

원하는 지역 이름으로 동네를 설정하고 도보 배달을 시작해 로켓까지 탈것을 바꾸는 가로형 브라우저 게임입니다.

## 실행

프로젝트 루트에서 다음 명령을 실행한 뒤 브라우저로 [게임 열기](http://localhost:4173)를 선택하세요. 별도의 빌드나 패키지 설치는 필요하지 않습니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory tap-tap-rider/dist
```

같은 와이파이에 연결된 휴대폰에서 테스트할 때는 `--bind 127.0.0.1` 대신 `--bind 0.0.0.0`을 사용하고, 휴대폰 브라우저에서 PC의 로컬 IP 주소와 포트 4173으로 접속합니다. 기기를 가로로 돌리면 이동 화면과 조작부가 한 화면에 표시됩니다.

## 플레이

- 첫 콜을 수락하면서 남성 또는 여성 라이더를 선택합니다. 설정에서 언제든 변경할 수 있습니다.
- 설정의 **배달 지역명**에 원하는 동네 이름(예: `부천`, `강남`, `해운대`)을 입력하면 거리 간판, 매장 이름(`부천버거`, `부천피자` 등 20종 음식), 주문서와 배달지가 모두 그 지역으로 바뀝니다. **거리 배경 분위기**(공방거리·가로수길·예술거리)도 별도로 고를 수 있습니다. 진행 중인 배달의 이동 거리와 운임을 이어서 플레이할 수 있습니다.
- 라이더는 자동으로 이동합니다. 이동 중 거리 화면이나 부스트 버튼을 탭하거나 스페이스바를 눌러 가속합니다. 연속해서 탭해도 가속 제한이 없습니다.
- 가게에서 음식이 맞는지 확인하고, 목적지에서 주차한 뒤 주문서의 호수를 찾아 전달합니다. 잘못된 배달은 고객센터에서 재배달 또는 감액 정산으로 처리할 수 있습니다.
- 차고에서 배달 수단과 장비를 구입합니다. 거리, 평점, 우천, 피크 시간대가 운임에 반영됩니다. 빠른 배달을 하루 3번 성공하면 미션 메뉴에서 2,200원을 받을 수 있습니다.
- 첫 배달 이후 새 콜이 5~10개 뜰 때마다 무작위로 정한 순서에 특별 콜이 한 번 등장합니다. 건너뛴 콜도 포함하며, 다음 등장까지 남은 콜 수는 저장되어 새로고침해도 유지됩니다. 광고 없이 일반 운임으로 즉시 수락하거나, 보상 광고를 보고 5배 운임으로 수락할 수 있습니다. 일반 콜처럼 건너뛸 수도 있습니다. 웹은 5초 보상 광고 테스트이며 Android 테스트 앱에서는 Google 공식 테스트 광고를 사용합니다.
- 업적 메뉴에서 30개 업적의 진행률과 달성 상태를 확인하고 보상을 한 번씩 수령합니다. 기존 저장 데이터의 배달 횟수, 누적 운임, 보유 탈것과 장비 강화 단계도 반영됩니다. 빠른 배달·별점·음식 종류는 남아 있는 배달 기록부터 복원하며, 예전 기록에 없던 우천·피크 여부는 업데이트 후부터 집계합니다.
- 소지금, 보유 장비, 라이더, 진행 중인 배달과 기록은 현재 브라우저에 자동 저장됩니다. 미니맵을 누르면 경로와 목표 시간을 확인할 수 있습니다.

게임 소스와 그림, 글꼴은 `tap-tap-rider/dist`에 있습니다. 배경음악과 효과음은 브라우저의 Web Audio API로 재생합니다.
